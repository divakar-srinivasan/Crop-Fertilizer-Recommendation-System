# Crop and Fertilizer Recommendation System

## Project Description

This repository contains the Review 1 crop recommendation prototype for a final-year ML project. Review 1 focuses on building a simple, reproducible crop classifier from soil parameters only.

Review 1 Level 3 trains and evaluates multiple baseline models, selects the best model using weighted F1-score, saves the selected model, provides a prediction module, and exposes a basic Streamlit interface.

## Technologies

- Python
- pandas
- scikit-learn
- Random Forest
- LightGBM
- XGBoost
- CatBoost
- joblib
- matplotlib
- Streamlit

## Dataset

The original crop dataset is stored at `data/crop_dataset.csv`. Level 3 does not train from the original 46-column file directly. It uses only the processed Level 2 outputs:

- `data/processed/X_train.csv`
- `data/processed/X_test.csv`
- `data/processed/y_train.csv`
- `data/processed/y_test.csv`
- `data/processed/label_encoder.joblib`

The Level 2 split contains 8,000 training rows and 2,000 testing rows. The target classes are:

- Maize
- Rice
- Soybean
- Wheat

## Selected Features

The model uses exactly these 12 soil features, in this order:

```text
N, P, K, pH, EC, OC, S, Zn, Fe, Cu, Mn, B
```

Target column:

```text
Crop_Type
```

## Prediction Module

`scripts/predict.py` loads the saved model and label encoder, validates all 12 soil inputs, creates the correct feature order, predicts the encoded class, and converts it back to the crop name.

Validation checks include:

- all 12 inputs are present
- inputs are numeric
- no NaN values
- no infinite values
- non-negative soil parameter values
- pH is between 0 and 14

Executed prediction test result:

```text
Predicted Crop: Maize
```

### Dataset V2 Feature Importance

Feature importance is reported as model-specific importance, not causal evidence. For the selected CatBoost model:

| Feature | Importance | Normalized Importance |
| --- | ---: | ---: |
| Soil_Moisture | 95.3105 | 0.9531 |
| Humidity | 1.9381 | 0.0194 |
| Temperature | 2.7514 | 0.0275 |

The prior Dataset V2 audit found unusually strong feature/crop separation:

- Soil_Moisture eta-squared approximately 0.9847
- Humidity eta-squared approximately 0.7037
- Temperature eta-squared approximately 0.2457

This means the very high Dataset V2 baseline accuracy is dataset-dependent and strongly influenced by crop-specific Soil_Moisture ranges. It should not be presented as proof of broad real-world generalization.
